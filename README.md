# 🌐 Personal Portfolio Website

A modern, responsive, and interactive personal portfolio built using **React.js**.  
This portfolio showcases my skills, projects, certifications, and contact information with a clean UI and animated effects.

🌍 Live Demo : 

---

## ✨ Features

- ⚡ Fully responsive design (Desktop & Mobile)
- 🎨 Neon glow UI with animated buttons
- 🖼️ Interactive home page with dynamic image preview
- 📂 Projects section with GitHub & Live links
- 📄 Resume integration
- 🏆 Skills & Certifications section
- 📬 Contact form with email support
- 🔗 Social media links (GitHub, LinkedIn, Gmail)
- 🏠 Home navigation button
- 🌈 Animated gradient effects

---

## 🛠️ Tech Stack

- **Frontend:** React.js
- **Styling:** CSS3
- **Icons:** SVG
- **Animations:** CSS Animations
